# Katkı / Contributing

Katkılar memnuniyetle karşılanır. / Contributions are welcome.

- **Hata ya da yanlış iddia:** Bir issue açın; mümkünse karşı örnek ya da kaynak ekleyin.
- **Yeni sonuç:** [`docs/05-acik-problemler.md`](docs/05-acik-problemler.md) listesindeki bir probleme ilerleme kaydettiyseniz, issue ya da pull request açın.
- **Lean:** Yeni ispatlar `sorry` içermemeli. `#print axioms` çıktısını PR açıklamasına ekleyin.
- **Atıf:** Bu çalışmaya dayanan her yayında `CITATION.cff` üzerinden atıf yapın (CC BY 4.0 gereği).

Issues and pull requests are welcome in Turkish or English. Please cite this work (see `CITATION.cff`) if you build on it.
